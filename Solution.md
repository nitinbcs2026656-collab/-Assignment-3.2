# Assignment 3.2 — Images in HTML

**File name:** `index.html`

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <title>My Portfolio</title>
</head>
<body>
    <h1>My Portfolio</h1>

    <h2>My Images</h2>

    <img src="images/photo1.jpg"
         alt="My profile photo" width="200" height="150">

    <img src="images/photo2.jpg"
         alt="Nature scenery" width="200" height="150">

    <img src="images/photo3.jpg"
         alt="My coding workspace" width="200" height="150">
</body>
</html>
```

**Folder structure:**
```text
project/
├── index.html
└── images/
    ├── photo1.jpg
    ├── photo2.jpg
    └── photo3.jpg
```

**Submission:** Add three images to the `images` folder, open `index.html` in the browser, verify that all images load, and submit the page with the images folder.
